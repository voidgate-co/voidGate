voidgatectl talks to /run/voidgate.sock. Prometheus, if metrics_port > 0, binds 127.0.0.1:9105/metrics.

voidgatectl

Command Effect
status state, armed, rx_pps, rx_bps, drop count, iface
stats XDP counters: rx_pkts, passed, dropped, non_ip, map_full, parse_err
drops installed prefixes with reason and age
arm cfg.armed = 1; re-baseline remote rate snapshots
disarm flush drop_*, cfg.armed = 0, back to IDLE
drop <cidr> manual insert; forces ACTIVE. Reason 1. Not auto-expired.
undrop <cidr> remove one prefix from the drop tree
reload re-read the config file; replace allow/local maps and ports
reload does not change the attached interface, XDP mode, or map sizes. Those are fixed at start.

Drop reasons: 1 manual, 2 policy, 3 aggregate.

Config

Key=value. Empty local_networks means auto-detect from the interface. A non-empty allow_networks replaces the built-in list (metadata, localhost, link-local).

configs/voidgate.conf 
# voidGate configuration
# Silent unless this VM's NIC is under DDoS. Control plane decides drops;
# XDP enforces a prefix-tree drop list.

# RX NIC for XDP. Packets are judged only on ingress; TX never runs this
# program. Default eth0. -i overrides. A missing name exits before BPF
# load. Do not attach to lo (local delivery never hits XDP). reload does
# not move the attach.
interface = eth0

# auto: native driver XDP, then skb generic. native / skb pin one mode.
# reload does not change mode.
xdp_mode = auto

# Aggregate NIC packets/sec from metrics.rx_pkts (every frame, including
# drops). IDLE→ACTIVE when rx exceeds this or wake_mbps. Keep
# threshold_pps below this so a flood split across sources still drops
# those source IPs after arm.
wake_pps = 2000

# Aggregate NIC megabits/sec from metrics.rx_bytes. Either wake_* arms.
# 25 Mbps is in the same ballpark as 2000 pps of MTU frames; small-packet
# floods trip wake_pps first. 1000 Mbps is line rate on a 1G VM.
wake_mbps = 25

# Userspace tick period in milliseconds. XDP stays attached in IDLE;
# this only polls coarse rx and, when ACTIVE, walks remotes. <= 0
# becomes 1000.
idle_poll_ms = 1000

# ACTIVE→IDLE after this many seconds of rx below both wake_* AND an
# empty drop tree. Policy/aggregate prefixes must expire (ban_time)
# first unless voidgatectl disarm.
clear_seconds = 30

# Per-remote packets/sec, ACTIVE only. Over this or threshold_mbps, drop
# packets from that source IP (XDP_DROP): one IPv4 address (/32) or one
# IPv6 address (/128). First sight of a source is a baseline; a rate
# needs two ticks. Keep below wake_pps.
threshold_pps = 500

# Per-remote megabits/sec. Same drop as threshold_pps. Keep below
# wake_mbps.
threshold_mbps = 5

# Seconds a policy or aggregate drop stays in the LPM tree. Manual
# voidgatectl drop entries do not expire.
ban_time = 1900

# When this many dropped hosts sit in one IPv4 /24 or IPv6 /64, drop
# that whole prefix too (reason=aggregate). Refused if the prefix covers
# local_* or allow_*.
aggregate_k = 8

# This VM's CIDRs. Empty: take addresses from the XDP NIC as /32 and
# /128 (skip loopback and fe80::/10) so LAN neighbors are not local.
# Non-empty CSV replaces auto. Dest in local_* is inbound to this VM
# (host/remote counters, allow_ports). Do not store the on-link LAN
# prefix: neighbors would count as local and could not be dropped.
local_networks =

# Never-drop LPM. Non-empty CSV replaces the built-in list entirely
# (it does not merge). Built-in: 169.254.169.254/32, 127.0.0.0/8,
# ::1/128, fe80::/10, ff02::/16. XDP also hard-passes IPv6 NDP types
# 133-137 with hop limit 255, and DHCP to this VM as an exact port pair:
# UDP 67->68 or 68/67->67 (DHCPv6 547->546 or 546/547->547), dest local
# or broadcast.
allow_networks = 169.254.169.254/32, 127.0.0.0/8, ::1/128, fe80::/10, ff02::/16

# TCP ports on the local side: dport with dest in local_*, or sport with
# src in local_*. CSV, at most 8. A remote source port of 22 is not a
# whitelist.
allow_ports = 22

# remote_v4 / remote_v6 LRU_PERCPU_HASH cap (attack sources, dest-local
# only). BPF_F_NO_PREALLOC: this is a cap, not preallocated RAM. Set at
# load; reload cannot grow it. Not flushed on disarm.
remote_map_size = 262144

# drop_v4 / drop_v6 LPM_TRIE cap. Same no-prealloc / reload rules.
# Aggregation to /24 or /64 is the relief when this fills.
drop_map_size = 65536

# 0 disables HTTP. Otherwise bind 127.0.0.1 and serve GET /metrics only.
metrics_port = 9105
Key Role
wake_pps / wake_mbps NIC is on fire → arm the gate
threshold_pps / threshold_mbps this remote is part of the attack → install a drop (keep below wake)
clear_seconds quiet time required (with empty drop tree) to return IDLE
ban_time seconds a policy/aggregate drop lives; manuals stay
aggregate_k dropped hosts in a /24 or /64 before aggregating
allow_ports TCP ports on the local side (default 22)
metrics_port 0 disables HTTP; otherwise localhost only

Prometheus

When metrics_port is positive, the daemon listens on localhost and serves GET /metrics:

/metrics

voidgate_armed 0
# TYPE voidgate_rx_packets_total counter
voidgate_rx_packets_total 0
# TYPE voidgate_rx_bytes_total counter
voidgate_rx_bytes_total 0
# TYPE voidgate_dropped_packets_total counter

voidgate_map_full_total 0

# TYPE voidgate_rx_pps gauge
voidgate_rx_pps 0

ACTIVE policy, short

Each tick, remotes over threshold become /32 or /128. Dense clusters become /24 or /64. Userspace will not install a prefix that covers the VM itself or the allow list. On disarm, remote_* stays; the next arm re-baselines snapshots so leftover counters are not a phantom flood.

A remote source port of 22 is not SSH. Only the local side of allow_ports is whitelisted. Do not drop the interface CIDR.
