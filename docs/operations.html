On this page

voidgatectl

Command Effect
status state, armed, rx_pps, rx_bps, drop count, iface
stats XDP counters: rx_pkts, passed, dropped, non_ip, map_full, parse_err
drops installed prefixes with reason and age
arm cfg.armed = 1; re-baseline remote rate snapshots
disarm flush drop_*, cfg.armed = 0, back to IDLE
drop <cidr> manual insert; forces ACTIVE. Reason 1. Not auto-expired.
undrop <cidr> remove one prefix from the drop tree
reload re-read the config file; replace allow/local maps and ports
reload does not change the attached interface, XDP mode, map sizes, log or pid file, or the metrics listener. Those are fixed at start. Reload does lift any installed drop, manual ones included, that now covers a local_* or allow_* prefix.

Drop reasons: 1 manual, 2 policy, 3 aggregate.

Config

One key = value per line; # starts a comment. Every key is optional, and the defaults below are also what ships in configs/voidgate.conf. The commented file explains each one in more depth.

Key Default What it does reload
Interface and files
interface eth0 RX NIC to attach XDP to. -i overrides. Never lo. restart
xdp_mode auto auto tries native driver XDP, then SKB. native / skb pin one. restart
log_file /var/log/voidgate.log Append-only log. Parent directory must exist. restart
pid_file /run/voidgate.pid Locked for the daemon's life; -s stop reads it. restart
Waking up
wake_pps 2000 Aggregate NIC packets/s that arms the gate (IDLE → ACTIVE). live
wake_mbps 25 Aggregate NIC Mbit/s that arms the gate. Either wake_* arms. live
idle_poll_ms 1000 Userspace tick in ms. <= 0 becomes 1000. live
clear_seconds 30 Quiet seconds, with an empty drop tree, before ACTIVE → IDLE. live
Dropping
threshold_pps 500 Per-remote packets/s that earns a /32 or /128 drop. Keep below wake_pps. live
threshold_mbps 5 Per-remote Mbit/s, same effect. Keep below wake_mbps. live
ban_time 1900 Seconds a policy or aggregate drop lives. Manual drops never expire. live
aggregate_k 8 Dropped hosts in one /24 or /64 before the whole prefix is dropped. live
Never drop
local_networks (auto) This VM's CIDRs. Empty takes the NIC's addresses as /32 and /128. Don't list the on-link LAN prefix. live
allow_networks metadata, loopback, link-local Never-drop CIDRs. A non-empty list replaces the built-in one; it does not merge. live
allow_ports 22 TCP ports whitelisted on the local side. CSV, at most 8. live
Capacity and metrics
remote_map_size 262144 Cap on tracked attack sources (LRU, not preallocated). restart
drop_map_size 65536 Cap on drop-tree prefixes (not preallocated). restart
metrics_port 9105 Prometheus on 127.0.0.1. 0 disables it. restart

live: voidgatectl reload applies it. restart: fixed when the daemon starts. The built-in allow list is 169.254.169.254/32, 127.0.0.0/8, ::1/128, fe80::/10, ff02::/16.

Lua client

lua/voidgate.lua talks to the same socket from Lua 5.1–5.4 or LuaJIT, using LuaSocket's socket.unix. Install it with sudo make install-lua LUA_VERSION=5.4.

lua 
local vg = require("voidgate")

local status = assert(vg.status())
print(status.state, status.armed, status.rx_pps)

assert(vg.drop("203.0.113.0/24"))
assert(vg.undrop("203.0.113.0/24"))

Every method returns nil, err on a connection, timeout or daemon error. stats() returns 64-bit counters as decimal strings. Calls block with a one-second default timeout, so the client suits standard Lua hosts, not an OpenResty request loop.

ACTIVE policy, short

Each tick, remotes over threshold become /32 or /128. Dense clusters become /24 or /64. Userspace will not install a prefix that covers the VM itself or the allow list. On disarm, remote_* stays; the next arm re-baselines snapshots so leftover counters are not a phantom flood.

A remote source port of 22 is not SSH. Only the local side of allow_ports is whitelisted. Do not drop the interface CIDR.
